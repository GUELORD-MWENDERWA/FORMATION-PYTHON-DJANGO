# Application de gestion de produits

Cette application a été séparée en plusieurs fichiers pour montrer les bases de Python et de la POO de manière progressive.

## Fichiers

- `models.py` : contient la classe `Product`
- `product_manager.py` : contient la classe `ProductManager`
- `utils.py` : contient les fonctions de saisie
- `main.py` : point d'entrée de l'application

## Notions abordées

- variables et types
- boucles `while`
- conditions `if/else`
- fonctions
- classes et objets
- propriétés
- encapsulation simple via méthodes
