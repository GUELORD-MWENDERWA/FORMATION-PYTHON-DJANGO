{% comment %} partials/messages.html - affiche les messages Django (succes, erreur, info...) envoyes par les vues via `messages.success(...)`, `messages.error(...)`, etc. Inclus une seule fois dans base.html, donc disponible sur toutes les pages qui l'etendent. Le framework django.contrib.messages est deja active dans settings.py (INSTALLED_APPS, MIDDLEWARE et le context processor "django.contrib.messages.context_processors.messages") : c'est ce qui rend la variable `messages` disponible ici sans qu'on ait besoin de la passer explicitement depuis une vue. Pour l'instant aucune vue n'appelle encore messages.success/error (elles se contentent d'un render()), donc ce bloc ne s'affiche jamais : ce sera utile des que les formulaires seront branches a de vraies actions (enregistrer un produit, se connecter, etc.). {% endcomment %} {% if messages %}
{% for message in messages %}
{{ message }}
{% endfor %}
{% endif %}
